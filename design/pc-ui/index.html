00 游戏登录 · 启动首屏

 打开 → 02 创建对局 · 座位分配

 打开 → 03 对局舞台 · 观战模式

 打开 → 04 对局舞台 · 入座对战

input_required 驱动的人类行动面板：发言 240 字 / 投票 / 技能 + 托管倒计时；沉浸视角。

 打开 → 05 终局 · 胜负与用量

末段才揭示的终局横幅 + 投票抽屉 + 用量面板（调用 / tokens / 费用 / 缓存 / 兜底 / 异常）。
