# 狼人杀（首发游戏）

游戏插件提供两套规则集（ruleset），板子按规则集选择：

| ruleset | 名称 | 状态 | 内容 |
|---|---|---|---|
| `minimal` | v1 最小流程局 | 首发验证用 | 狼 + 预言家 + 平民，6-10 人，无警长 |
| `standard-9` | 标准 9 人局 | 完整设计 | 预女猎 + 3 民 + 警长系统，9 人（无守卫/狼王，见第四章） |
| `standard-12` | 标准 12 人局 | 完整设计 | 预女猎守 + 狼王 + 警长系统，12 人 |

规则参考自 [whoisspy.ai 十二人局核心规则](https://whoisspy.ai/#/competitionDetail?&id=13&muxsearch=%7B%22type%22%3A%22rule%22%7D)（AI 狼人杀对抗赛），吸收其对局规则语义；其评分/匹配/下线机制属比赛平台功能，不在本项目范围（见 [roadmap.md](../roadmap.md)）。

---

## 一、两套规则集共用的核心约定

- **发言上限 240 汉字**，超出截断（与参考平台一致，保证观赛节奏与 token 可控）。
- **遗言**：被投票出局的玩家发表遗言（`phase=last_words`，public）。夜里死亡无遗言（与参考平台一致）。
- **狼队定刀**：并行 gather 各狼目标提案，**得票最高**为目标；平票用对局 rng（种子/分布/决胜入事件）。**无合规目标（非法编号/未返回/弃权）= 空刀（放弃刀人）**——规则层与引擎兜底都空刀，绝不随机替狼做主。
- **胜负检查时机**：每个死亡结算点（夜死、开枪、放逐）之后立即检查。
- 随机性（发牌、发言人起点、定刀平票）全部走对局带种子 rng 且结果写入事件（[architecture.md](../architecture.md) 支柱 1）。

### 角色一览

| 角色 | 阵营 | 技能 |
|---|---|---|
| 平民 | 好人 | 无技能，靠发言与投票 |
| 预言家 | 好人 | 每晚查验一人，得知「好人/狼人」 |
| 女巫 | 好人 | 解药×1（救当晚被刀者）、毒药×1（毒杀一人），**每晚最多用一瓶** |
| 猎人 | 好人 | 死亡时可开枪带走一人；**被毒死不能开枪** |
| 守卫 | 好人 | 每晚守护一人免于狼刀（可守自己，**不能连续两晚守同一人**） |
| 普通狼人 | 狼人 | 每晚参与击杀决策 |
| 狼王 | 狼人 | 同普通狼人；**死亡时可开枪**（规则同猎人，被毒死不能开枪） |

### 夜间结算矩阵（standard-12）

夜晚行动顺序：**守卫守护 → 狼人落刀 → 预言家查验 → 女巫行动**，随后向猎人/狼王发技能状态通知（能否开枪）。

死亡效果优先级（参考规则原文「狼杀 > 女巫毒 > 守卫救人 > 女巫救人」）落地为结算矩阵。设刀口 K、守卫目标 G、是否用解药 S、毒目标 P：

| 情形 | 结果 | 死因 |
|---|---|---|
| P 被毒（任意组合） | **死亡**（守卫与解药都不挡毒） | poison（不能开枪） |
| K = G 且 S（同守同救） | **死亡**（守卫悖论） | knife ※ |
| K = G 且未救 | 免死（守卫成功） | — |
| K ≠ G 且 S | 免死（救活） | — |
| K ≠ G 且未救 | 死亡 | knife |
| K = P（同刀同毒） | 死亡，死因按优先级认定 | knife（可开枪）※ |

※ 规则原文未覆盖的两处，按常见面杀惯例补全（待确认清单见文末）：悖论死与刀毒同人死均认定为刀杀（可开枪）。

- 女巫的刀口信息：**仅在使用解药时知晓当晚死者**（规则原文「仅限首次使用时知晓死者信息」）。落地：女巫行动请求中，解药尚在则附当晚刀口供决策；解药已用则不再提供刀口。
- 空刀之夜无人死于刀（女巫无法对空刀口用药）→ 平安夜。

## 二、v1 最小流程局（ruleset: minimal）

6-10 人：狼 1~⌈n/3⌉、预言家 0~2、平民 ≥1（发牌校验越界拒绝创建）。

**流程状态机**：

```
NIGHT_WOLF（狼队商量 + 定刀，可空刀）
  → NIGHT_SEER（预言家验人，可跳过）
  → DAWN（结算夜死，公布死讯；无开枪环节）
  → DAY_SPEECH（存活玩家按序发言，240 字截断）
  → DAY_VOTE（并行投票放逐）
  → 被投出者遗言（last_words）
  → 胜负检查 → 未分胜负回到 NIGHT_WOLF
```

**胜负**：好人胜 = 狼全灭；狼胜 = 存活狼 ≥ 存活好人。可配**天数上限**（默认第 8 天白天结束仍有狼存活 → 狼胜），防止无限拉锯。

**相对参考规则的取舍**（v1 求简）：

- 无警长、无女巫/猎人/守卫/狼王 → 无开枪、无守卫悖论。
- 白天投票**平票 = 平安日**，无人出局（不做 PK，比随机出局更正统且无随机）。
- 无遗言的夜死规则、240 字上限、空刀规则与 standard-12 一致（共用约定）。

## 三、标准 12 人局（ruleset: standard-12）

**配置**：12 人 = 狼人阵营 4（普通狼×3 + 狼王×1）+ 好人阵营 8（预言家 + 女巫 + 猎人 + 守卫 + 平民×4）。

**胜负**（满足任一即结算）：

- **狼胜**：所有神职（预/女/猎/守）全部出局，**或**平民全部出局，**或**存活狼数 ≥ 存活好人数，**或**第 8 天白天结束仍有狼存活。
- **好人胜**：狼人阵营（含狼王）全部出局。

（即屠边 + 屠城混合：神职屠边、平民屠边、屠城、时限四条狼胜路径。）

### 夜晚流程

顺序：**守卫守护 → 狼人落刀 → 预言家查验 → 女巫行动 → 猎人/狼王技能状态通知**（`skill_state.notice`：告知当前能否开枪，god→本人）。

结算按上文夜间结算矩阵。夜死公布时同步处理开枪与警徽（见白天流程 iv）。

### 警长竞选（仅第 1 天，夜末、死讯公布前）

第 1 天夜末（最后夜行动之后、公布死讯之前）执行竞选；其余天数无此环节（D21，推翻 D20 的「发言后竞选」）。

1. 全体并行选择是否上警。
2. 恰 1 人上警：自动当选；无人上警或全员上警：**警徽丢失**。
3. 警上发言：rng 随机选一名上警玩家起始，上警玩家依次发表竞选宣言。
4. 警长投票：**未上警玩家**投票（并行收集）；得票最多者当选。
5. 平票 → PK：平票者再次发言，**其余所有玩家**（含已上警者）投票；再平票 → 警徽丢失。

### 白天流程

**i. 夜晚死亡信息公布**

1. 宣布昨夜死亡玩家或平安夜（死因不公布；开枪会暴露猎人/狼王身份）。
2. 死亡的猎人/狼王（非毒死）**立即开枪**带人（SoloAction，目标须为存活玩家），被枪杀者无遗言、不能连锁开枪（死者若是猎人/狼王已用掉本次开枪）。
3. 警长死亡：立即选择**移交警徽**给存活玩家或**撕毁警徽**（继承人即刻获得全部警长权力）。

**ii. 白天发言**

1. 有警长：警长先决定发言顺序（顺/逆时针，从警长左手或右手邻座起始）。
2. 无警长：rng 随机玩家起始，按座位号顺序。
3. 发言 240 字截断。

**iii. 投票放逐**

1. 警长可**归票**（末位表明投票意向，属发言内容）。
2. 全体并行投票，**警长 1 人 2 票权重**；得票最多者出局。
3. 平票 → PK：平票者再次发言，全体再投；仍平票 → **平安日**，无人出局。

**iv. 技能触发**（出局结算顺序：开枪优先于其他技能）

1. 被投出者发表遗言（last_words）。
2. 被投出的猎人/狼王可开枪（非毒死时），确认出局后立即触发。
3. 警长被投出：开枪结算后移交警徽或撕毁。

每一步死亡（夜死/枪杀/放逐）之后立即做胜负检查。

### 警长权力与警徽

| 项 | 规则 |
|---|---|
| 发言顺序 | 每个白天发言前决定顺/逆时针 |
| 投票权重 | 2 票 |
| 归票 | 投票前可表明意向（影响跟票） |
| 移交 | 死亡时必须移交（存活玩家）或撕毁；两种时机：夜死公布时、被投出时；继承人立即生效 |
| 丢失 | 无人上警、全员上警、PK 再平票、主动撕毁 → 本局不再有警长 |

## 四、标准 9 人局（ruleset: standard-9）

**配置**：9 人 = 狼人阵营 3（普通狼×3）+ 好人阵营 6（预言家 + 女巫 + 猎人 + 平民×3）。**无守卫、无狼王**，固定组合不可 custom 改神职数（D15，`STANDARD9_ROLES` 校验）。

**胜负**：与 standard-12 完全一致（`check_winner` 按 `ruleset.startswith("standard")` 同一套分派，屠边 + 屠城混合四条狼胜路径）：

- **狼胜**：所有神职（预/女/猎）全部出局，**或**平民全部出局，**或**存活狼数 ≥ 存活好人数，**或**第 8 天白天结束仍有狼存活。
- **好人胜**：狼人阵营全部出局。

**流程**：复用第三章全部白天流程与警长系统——夜末警长竞选（D21，死讯公布前）→ 公布死讯 → 白天发言 → 投票放逐（PK、开枪、警徽移交/撕毁、警长 2 票权重均相同）。差异仅在夜间：

- **无守卫步**：夜序为 **狼人落刀 → 预言家查验 → 女巫行动 → 猎人技能状态通知**。状态机的 `NIGHT_GUARD` 由角色存活驱动自动跳过（场上无守卫角色），无需为板子写分支。
- **结算矩阵简化**：守卫相关情形不存在（无同守同救悖论、无守卫免刀）；同刀同毒、女巫双药（每晚一瓶、刀口信息时机、不挡毒）语义与 standard-12 相同。
- **开枪**：仅猎人（无狼王），夜死公布与放逐结算时的开枪规则同 standard-12（被毒死不能开枪、不连锁）。

一句话：standard-9 = standard-12 去掉守卫与狼王、平民 4→3 的紧凑版，全部机制按 `standard` 前缀共用分派。

## 五、状态机（standard-12 / standard-9）

```
夜循环：
  NIGHT_GUARD → NIGHT_WOLF（频道商量+定刀）→ NIGHT_SEER → NIGHT_WITCH
  [→ 第 1 天：SHERIFF_REGISTER → SHERIFF_SPEECH → SHERIFF_VOTE [→ SHERIFF_PK → 重投]]
  → DAWN（结算矩阵出死讯 → 连锁：开枪 → 移交警徽）
  → DAY_SPEECH_ORDER（警长定序）→ DAY_SPEECH
  → DAY_VOTE [→ DAY_PK → 重投]
  → EXILE_RESOLVE（遗言 → 开枪 → 移交警徽）
  → 胜负检查 → 未分胜负进入下一夜
```

多个夜间动作（守卫/狼刀/验人/用药）可并行收集时互不通气——其中狼队内部先经频道商量（见下）。开枪/移交/定序都是 SoloAction。执行语义见 [game-plugin.md](../game-plugin.md)。

standard-9 使用同一状态机：场上无守卫角色时 `NIGHT_GUARD` 自动跳过（wolf_meeting 直接起始）；无狼王时开枪仅由猎人触发。

**狼队夜间商量**：与 v1 共用 ChannelMeeting——轮内串行发言（`rounds` 默认 2，0~3 可配，每狼总调用 ≤ rounds+1，失败不补轮），收刀并行提案多数决，平票 rng，无合规目标 = 空刀。

## 七、板子（boards.json）

| id | ruleset | 角色组合 | 备注 |
|---|---|---|---|
| `p6-classic` | minimal | 2 狼 + 1 预 + 3 民 | v1 默认 |
| `p8-classic` | minimal | 2 狼 + 1 预 + 5 民 | |
| `p10-no-seer` | minimal | 3 狼 + 7 民 | 无预言家压力测试 |

  1. 同守同救悖论死的死因认定（暂定 knife，可开枪）。
