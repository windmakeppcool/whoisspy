# 前端视觉设计规范（观赛页）

本文档是前端视觉的**唯一权威**：观赛页（后续含列表页/创建页）的配色、字体、布局、组件形态都以此为准。设计稿工程在 `frontend/`（Vue 3 + TS，mock 数据驱动）；单文件展示成品在 [`design/showcase.html`](../design/showcase.html)（双击即可在浏览器打开，无需构建）。

设计方针：**贴纸卡通风**——墨线描边、硬投影、Q 版角色、活的昼夜场景。避开的默认款：奶油底衬线大标题、暗底荧光单色、报纸细线风。

## 设计理念

whoisspy 的页面不是「仪表盘」，是**一张卡通牌桌**：观众围坐观看 12 个 AI 在村庄里互骗。狼人杀最本质的视觉语言是**昼夜交替**——它被选为签名元素，整页背景是一幕活的场景，其余元素全部克制以衬托它。

## 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| display | **站酷快乐体**（ZCOOL KuaiLe） | 品牌名、横幅标题、抽屉标题（卡通人格担当，克制使用） |
| body | **Noto Sans SC** | 发言正文、UI 文案 |
| num | **Baloo 2** | 座位号、票数、天数等数字（圆体呼应卡通） |

层级：发言正文 14px/1.62；旁白 13.5px 粗体胶囊；座位名 14.5px/900；模型名与辅助文字 11px `#8A85A0`；横幅标题 19px display 体。**重量表达层级**：900（姓名/按钮）、700（正文强调）、500（辅助）。

## 布局

三栏网格：`座位列(左 170~230px) ｜ 中央剧场(弹性) ｜ 座位列(右 170~230px)`，最大宽 1500px 居中。

```
┌──────────────────────────────────────────────────────┐
│ 🐺 whoisspy   [🎮 游戏模式 ▾]              [🙈/👁️ 视角] │ 顶栏（透明，融入天空）
├──────────┬──────────────────────────────┬──────────────┤
│ 座位 1-6  │  🌙 第 1 夜 · 狼队密谋  〔第1夜〕 │  座位 7-12   │

│ 阵营边条 │ │  [🦊] 发言气泡 ←左          │ │  角色徽章    │ │

│ 死亡✖   │ │  粉色狼队频道气泡（god）     │ │  死亡✖      │ │
│          │ │  虚线框内心独白（god）       │ │             │ │
```

- 视口高度内完整呈现牌桌（`overflow: hidden` 页面 + 剧场内滚动），对话是主角。
- ≤900px：座位列折叠到剧场下方横排，剧场优先。

## 签名元素：昼夜天光系统

`SkyBackdrop.vue`（fixed 底层）：整页天空随对局 `phase` 2.4s ease 过渡——

- **夜**：深蓝渐变天空、34 颗错频闪烁星星、月牙（叠圆法）、墨色村庄剪影（房子+旋转风车）。
- **昼**：亮蓝天空、太阳（双层光环）、绿坡、绿色村庄。
- 太阳/月亮是**同一颗天体**换色换位；CSS 背景均为 token 变量，组件只接 `phase` prop。
- `prefers-reduced-motion` 下风车停转、星星/呼吸点动画关闭（global.css 全局兜底）。

## 视角与信息层级

双视角是信息设计的一部分：沉浸视角下网络层即无敏感数据（服务端过滤），前端再兜底过滤狼队频道/独白/角色徽章/阵营边条；上帝视角全亮。切换入口常驻顶栏，快捷键 `G`。

## 动效清单（克制原则）

只保留服务理解的动效，其余不做：昼夜过渡 2.4s（签名）、星星错频闪烁、风车 9s/圈、发言座位弹起+呼吸点、按钮 hover 上浮 1-2px、投票条 0.5s 展开、新气泡随文档流自然出现。禁用：入场动画编排、滚动触发 reveal、无意义脉冲。

## 无障碍与质量底线

键盘焦点 3px `--sheriff` 轮廓；`aria-label` 覆盖交互元素与角色列表；`prefers-reduced-motion` 全局尊重；页面纵向完整不出滚动条；正文对比度满足阅读（发言墨字/白底）。

## 演进约定

- 改配色/字体/组件形态 → 先改本文档与 `tokens.css`，再动组件。
- 新页面（列表/创建）复用：天空场景层、贴纸质感公式、字体三角色、视角常量。
- 新游戏插件 → 复用布局与昼夜系统（无昼夜语义的游戏用 phase→场景映射表扩展）。
- 设计稿工程 `frontend/` 的导演条/mock 数据为演示工具，接 SSE 时由 `api/sse.ts` + store 替换（见 [frontend.md](frontend.md)）。
